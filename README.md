# 中国出口管制实体与政策情报台

面向政策与贸易情报研究的交互式网页，统一展示中国商务部公开的出口管制管控名单、不可靠实体清单和关注名单，并提供实体检索、公告筛选、政策时间轴、国家下钻及替代进口供应链研判。

## 主要模块

- 首页：实体、公告、国家/地区和管制类型统计
- 管制企业清单：按关键词、国家/地区、年份、主体属性和管制类型筛选
- 公告库：按管制类型、国家/地区和年份筛选官方公告
- 政策时间轴：按时间展示三类监管机制的政策演进
- 穿透研判：展示经公开信息和贸易数据验证的潜在替代进口链路

## 本地运行

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

生产构建与局域网启动：

```bash
npm run build
npx vinext start --hostname 0.0.0.0 --port 3000
```

## 数据说明

实体和公告信息以中华人民共和国商务部、中国出口管制信息网公开页面为主要来源。供应链研判用于风险排序和研究，不构成对违法行为的认定或法律意见。
